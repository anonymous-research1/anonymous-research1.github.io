Abstract

This project introduces simulation-ready object assets that combine object-scale geometry, tactile micro-geometry, and dynamic surface temperature fields for contact-rich robotic simulation.

The reconstructed assets support visual rendering, optical tactile simulation under matched contacts, and spatiotemporal thermal queries within a unified object representation.

Method Overview

Method figure will be placed here

Our pipeline reconstructs a coarse metric object mesh, registered tactile micro-height fields, and a dynamic surface-temperature field. These modalities are combined into a unified simulation-ready object asset that can be queried during contact-rich simulation.
